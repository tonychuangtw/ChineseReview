# 中文複習 — 成語・俚語・字音・字形

純靜態單頁應用（vanilla HTML/CSS/JS，無框架、無 build step、無外部依賴），可直接以 `file://` 開啟或部署到 GitHub Pages。所有資料只存在瀏覽器 localStorage，無任何網路請求。

## 功能

- **年級分層**：國小1-6／國中7-9／高中10-12，每題掛年級標籤；可選「只練本年級」或「含以下年級」
- **注音／拼音切換**：右上角一鍵切換，字音/字形題的標音即時跟著換
- **每日練習**：每天一回（同日同年級題目固定），混合各類題型；每題答完即看解說，答錯的題目重做到全對才算完成；完成紀錄供家長檢視（哪天做了、第一次答對率、錯了哪些題、花多少時間）
- **成語**（400 題）：釋義選擇、例句克漏字、**同義成語**三種題型隨機出，附常見誤用辨析；國高中含歷屆會考/學測常考成語
- **俚語諺語**（160 題）：台灣常見俚語、諺語、歇後語意義配對
- **字音辨正**（300 題）：破音字、易讀錯字，比照國語文競賽題型，以教育部審訂音為準
- **字形辨正**（300 題）：錯別字選擇 + **手寫模式**（看注音寫國字：畫布手寫 → 翻答案 → 自評，錯的進錯題本）
- **閱讀測驗**（42 篇題組）：白話與文言，國中比照會考、高中比照學測題組風格，每題附解說
- **錯題本**：答錯自動收集、可一鍵重練
- **字卡複習**：Leitner 三盒間隔複習（盒1每天、盒2每2天、盒3每5天），答錯的成語俚語自動入盒
- **進度**：各類答題數、正確率、每日練習日曆（家長檢視）
- **成語配圖**：部分成語附 AI 生成插圖（`img/idioms/<id>.webp`），字卡與答題解說會自動顯示
- **雲端同步**：右上角 Google 登入後進度跨裝置同步（見 js/sync.js）

題目內容以教育部頒定成語典、《國語一字多音審訂表》口徑為選材範圍，題目文字皆為原創撰寫。

## 檔案結構

```
index.html          主頁面
css/style.css       深色主題樣式（mobile-first）
js/app.js           應用邏輯（含純函式層，node 可測）
js/sync.js          Google 登入 + 雲端進度同步
js/data/idioms.js   成語題庫（含 syn 同義詞、src 歷屆出處）
js/data/slang.js    俚語諺語題庫
js/data/phonics.js  字音題庫
js/data/chars.js    字形題庫
js/data/reading.js  閱讀測驗題組
img/idioms/         成語配圖（tools/gen-idiom-images.js 生成）
tools/gen-idiom-images.js  Gemini 生圖批次腳本（本機跑，非站台程式）
test/test.js        資料完整性與題目生成測試（node test/test.js）
test/zy-check.js    注音↔拼音一致性檢查（node test/zy-check.js）
```

## 開發

無 build。改完直接重整瀏覽器。提交前跑 `node test/test.js` 和 `node test/zy-check.js`（加題最容易錯的就是注音拼音不一致，這支會抓出來）。
