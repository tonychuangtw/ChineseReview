# 深度解析指示詞（Tony 2026-08-03 定案，同日修訂：成語不含國字拆解）

撰寫或請 AI 生成題目「深度解析」時，一律用下面的指示詞。產出存入題目條目的 `deep` 欄位（多行字串，`\n` 分行），前端會自動顯示在答題回饋與單元教學卡。

## 成語指示詞（deep＝典故與成語意思）

> 請為成語「＿＿＿＿」寫「典故與成語意思」，繁體中文、台灣用語：
> - **典故由來**：出處原文（書名＋引文），後世引用脈絡。出處不確定寧缺勿錯，不可杜撰；無特定典故的組合式成語就寫「由字面組合而成，無特定典故」。
> - **字面意思**：一句話直譯。
> - **引申意思**：每種用法附使用情境或例子；有褒貶、常見誤用要註明。

格式（`\n` 分行）：
```
典故由來：……
字面意思：……
引申意思：……
```

## 字音（phonics）／字形（chars）指示詞（deep＝注音比較＋國字拆解）

> 請為「＿＿」（目標字「＿」）寫深度解析，兩段格式，注音以教育部《國語一字多音審訂表》審訂音為準：
>
> 1. **注音比較**：
>    - 字音題：目標字的所有審訂讀音逐一列出，每個讀音附 2 個代表詞；選項中「不存在的讀音」要標「無此音」。
>    - 字形題：正確字與各誤字的讀音並列（同音／近音要點出），各附代表詞。
> 2. **國字拆解與造字原因**：拆解部件（形聲字標聲符／義符），造字本義，並說明為何不同讀音（字音題）或易混字（字形題）對應不同意思。

格式：
```
1. 注音比較
……
2. 國字拆解與造字原因
……
```

## 錯誤選項也要解析（出題規則，已內建於前端）

- **成語題**：其他 3 個選項的成語各附成語意思（前端自動從題庫 `meaning` 帶出）。
- **字音題**：同字誤讀的正確用法寫進 `note`；借自他題的第 4 個讀音前端自動標出處。
- **字形題**：每個誤字的正確用法寫進 `note`（如「『完』是結束」）。

## 欄位與流程

- `deep` 為選填欄位，`idioms`（典故）/ `phonics` / `chars` 支援；內容逐條人工撰寫或人工核對後才入庫（⚠️ 不可交 subagent 量產）。
- 補完順序照 roadmap：由低年級往高年級，每日分批。
- 改完跑 `node test/test.js` 與 `node test/zy-check.js`。
- 範例：`js/data/idioms.js` i013（成語典故）、`js/data/phonics.js` p001（字音）、`js/data/chars.js` c001（字形）。
